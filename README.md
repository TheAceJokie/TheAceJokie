# AI Stock Trading Agents

מערכת מסחר אוטונומית מבוססת סוכני AI למניות אמריקאיות (דרך Alpaca), בסגנון Swing.

> ⚠️ **אזהרה חשובה:** אף מערכת לא מבטיחה רווח בשוק ההון. הערך של המערכת הוא משמעת + ניהול
> סיכונים קשיח + בדיקה קפדנית — לא ניבוי קסום. **תמיד מתחילים ב-Paper Trading** עד שיש הוכחת
> רווחיות יציבה לאורך זמן. אתה אחראי לכל פעולה ולכל הפסד.

## עקרון העל
**ה-LLM מציע, הקוד הדטרמיניסטי מחליט ושומר.** ה-LLM אף פעם לא שולח פקודה ישירות,
אף פעם לא מחזיק את מפתחות הברוקר, ואף פעם לא מחשב מספרים — כל החישובים נעשים ב-Python.

## מבנה
```
src/
  models.py        # סכמות נתונים (pydantic)
  config.py        # טעינת קונפיגורציה וסודות מ-ENV
  risk/            # מנוע הסיכון הדטרמיניסטי — הגרעין שמגן מהפסד
  data/            # נתוני שוק מ-Alpaca + חישוב אינדיקטורים
  screener/        # סינון יוניברס דטרמיניסטי (ללא LLM)
  execution/       # שליחת bracket orders ל-Alpaca
  orchestrator/    # הצינור שמריץ הכל
tests/             # בדיקות — בעיקר למנוע הסיכון
```

## התקנה
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # ומלא את המפתחות (Paper) שלך
```

## הרצת בדיקות
```bash
pytest -q
```

## שלבי פיתוח
- **שלב 0 (נוכחי):** שלד בטוח בלי AI — Alpaca Paper, סינון, מנוע סיכון + בדיקות, ביצוע.
- **שלב 1:** Backtesting + walk-forward.
- **שלב 2-3:** שכבת LLM וסוכני התפקיד.
- **שלב 4:** הרצת Paper ממושכת ואיסוף מדדים.
